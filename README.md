# Hermes 安装加速器（国内网络友好）

在国内网络下**一键安装 / 更新 [Hermes Agent](https://hermes-agent.nousresearch.com/)**，绕开几个常见的"卡住/装不上"的坑。双击即用，全程中文。

## 解决什么问题

在国内装 Hermes 常卡在这几处：

1. **安装脚本地址被墙** —— 官方安装器要从 `raw.githubusercontent.com` 拉脚本，该域名在国内常解析失败（`dns error`）。
2. **组件下载慢** —— 官方逻辑先试 `github.com`，失败才切镜像；可 github 在国内是"能连但被限速到几十 KB/s"，于是一直卡在慢线上。
3. **镜像域名被拦** —— 部分网络会拦掉一些"代理类"域名，导致镜像也用不了。
4. **代理残留** —— 代理设置留在系统里，后续升级会被"死代理"卡住。

本工具把上面这些都处理掉了。

## 功能

| 菜单 | 作用 |
|---|---|
| `[1]` | 安装 / 重装 Hermes（走国内镜像，**不用 VPN**） |
| `[2]` | 安装（走 VPN 代理，备用） |
| `[3]` | 一键恢复（清掉所有代理残留） |
| `[4]` | 查看当前状态 |
| `[5]` | **检查并更新 Hermes**（收到更新提示时用它，不用桌面端） |

工具会自动：
- **安装前先测速**：代码仓库、Python 依赖、npm 包、uv / PortableGit 等**全部**在多个国内镜像里**实测速度、挑最快的**用；
- 预先下好官方安装脚本、喂给安装器，**绕开被墙的 `raw.githubusercontent.com`**；
- 下载时**镜像优先**（官方地址会自动套国内代理一起比速度），避免卡在 github 慢速上；
- 更新时**屏幕全中文**，官方英文细节写进 `更新日志/` 文件夹（出问题可排查）。

## 使用

1. 下载本仓库，双击 **`Hermes安装加速器.exe`**
2. 选 **[1]**（安装）或 **[5]**（更新）
3. 跟着中文提示走即可

> 更新前请**完全退出** Hermes 桌面端（点 × 只是最小化到托盘，要右键托盘图标选【退出】）。

若杀毒软件误报 exe（自制 exe 常见误报），可用功能相同的 **`Hermes安装加速.bat`**。

## 文件说明

| 文件 | 说明 |
|---|---|
| `Hermes安装加速器.exe` | 单文件主程序（约 42 KB，已内嵌脚本，双击即用） |
| `Hermes安装加速.bat` + `hermes-vpn.ps1` | 同上功能的老方式（配套使用，备用/可读源码） |
| `全局代理开关.bat` + `proxy.ps1` | 通用代理开关（装别的东西时用） |
| `_打包器.cs` | 打包器源码（把脚本重新打成 exe） |
| `使用说明.txt` | 详细图文说明 |

> `Hermes-Setup.exe`（约 7.9 MB 的官方安装包）**不在仓库里**：工具在需要时会**自动联网下载**。你也可以把它放到工具同目录。

## 注意

- 本工具只是**加速/铺路**，安装的是官方 Hermes，脚本来源为官方地址或其国内镜像。
- 走镜像的路线**不需要 VPN**；只有 `[2]` 那条备用路线才需要。
- 网络环境千差万别，若仍装不上，多半是该网络对域名限制较严，可尝试更换网络。
