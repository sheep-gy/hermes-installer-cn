================================================
     使用说明
================================================

先看清楚用哪个：

   ★ Hermes安装加速器.exe  ← 推荐！双击即用（单文件，不用带别的东西）
     Hermes安装加速.bat    ← 老方式（和 hermes-vpn.ps1 配套，留作备用）
     全局代理开关.bat      ← 通用开关，装别的东西时用

双击就能跑，用完都不会留尾巴。

（exe 和 bat 功能完全一样，随便用哪个。
  万一杀毒软件拦 exe，就用 bat 那个。）


================================================
  第一部分：Hermes 安装加速
================================================

【一、以前为什么装不上 / 升级坏掉】

你原来那个 hermes-setup-vpn.bat，我读过了，
思路是对的（临时设代理），但有两个坑：

  坑 1：端口写死了
        里面写的是 127.0.0.1:13004。
        可 LeapVPN 会换模式 —— 你后来切到了
        "全局模式"（TUN 虚拟网卡），这时候
        根本没有 13004 这个端口。
        于是 git 被指到一个"死代理"上，反而装不上。

        证据在你的日志里（10-04 23:12 那次）：
        fatal: unable to access 'https://github.com/...':
        Failed to connect to github.com port 443
        via 127.0.0.1 after 2091 ms
              ↑↑↑ 走了本地代理，但那个端口连不上

  坑 2：只管设、不管收
        设置如果留在系统里，Hermes 桌面端以后
        升级时会一直走那个死代理 —— 这就是你说的
        "哪个端口没恢复原样，导致没法升级"。

【二、新工具怎么解决】

一句话：现探测端口 → 临时设 → 装完自动收干净。

    ★ 另外：安装前会自动【测速】—— 代码仓库、Python 依赖、
      npm 包等，都会在几个国内镜像里**实测速度、挑最快的**用，
      不会再卡在某个慢镜像上（详见下面【更新 Hermes】一节）。

    双击后选 [1]，它会：

      ① 现探测 LeapVPN 的代理端口
         （不写死 —— 端口会变，写死了就会踩老 bat 那个坑）
      ② 验证代理真的能通（GitHub 和 Google 各测一次）
      ③ 临时设好代理（系统代理 + 环境变量 + git 三处）
      ④ 启动 Hermes 安装程序，等它装完
      ⑤ 自动把刚才设的全部收干净
      ⑥ 复查一遍，确认系统里没有残留

    ★ 走代理是【必须】的，不靠"全局模式自动接管"。
      因为全局模式常有分流规则：github.com 走了 VPN，
      但真正下文件的 codeload.github.com、
      objects.githubusercontent.com 可能被漏掉，
      表现就是"能连上，但下不动"。

【三、★ 你需要先把 LeapVPN 切成【代理模式】】

LeapVPN 的两种模式：

    全局模式 / TUN 模式
        → 有虚拟网卡（LeapVPN Tunnel）
        → 这种模式【没有代理端口】，本工具用不了

    代理模式 / 系统代理模式
        → 会开出本地代理端口（一般是 13004）
        → ★ 装 Hermes 请用这个模式

切好之后，本工具才能探测到端口、才能设代理。

（如果你切了模式但还是探测不到，本工具会明确告诉你
  是"没连节点"还是"模式不对"，并给出下一步怎么做。）

【三·补、在新电脑上装不了？看这里】

    有些网络下，官方安装程序会卡在这一步报错：
       GET https://raw.githubusercontent.com/...  dns error
    （这个域名在国内常被墙）

    ★ 现在的版本会自动【先把安装脚本下好、再喂给安装器】，
      绕开这个被墙的地址；并且会把脚本改成【镜像优先】，
      免得卡在 github 的慢速上（国内 github 只有几十 KB/s）。

    你什么都不用做。万一还是不行，就开 VPN 走 [2] 那条路。

【四、怎么用】

    ① 打开 LeapVPN，切成【代理模式】，连上节点
    ② 双击 Hermes安装加速器.exe（或 Hermes安装加速.bat）
    ③ 选 [1]
    ④ 它会先验证代理通不通，通了才弹出安装窗口
    ⑤ 跟着安装窗口走，正常装
       ★ 装完先别急着关那个黑窗口 ——
         等它提示"已收尾"再关（它在帮你清理残留）
    ⑥ 想确认干净了没，选 [3] 看最后一行

另外菜单还有：

    [2]  一键恢复原样
         不管是谁留下的代理残留（系统代理、环境变量、
         git 配置），一次全清掉。以前被老 bat 弄脏的
         现在可以用这个洗干净。

    [3]  查看当前状态
         会告诉你：代理端口有没有、GitHub 通不通、
         有没有代理残留。

    [5]  检查并更新 Hermes   ★ 收到更新提示时用它
         （详见下面【更新 Hermes】一节）


================================================
  更新 Hermes（收到更新提示时，用它）
================================================

【什么时候用】

    Hermes 弹窗提示"有新版本"时，你不用点它那个更新按钮，
    改从本工具更新 —— 双击 Hermes安装加速器.exe，选 [5]。

【[5] 做什么】

    ① 先看你有没有把 Hermes 关干净
       （没关它会拦下来提醒你先退出，不会硬来）
    ② 自动更新：拉最新代码 + 重装依赖 + 刷新桌面程序
    ③ 完成后提示你可以打开 Hermes

    全程都是【中文】进度。Hermes 那些英文原始信息，
    会自动存到旁边的「更新日志」文件夹里 ——
    平时你不用管，万一更新出问题，把日志发给我就行。

【用过一次就会了的三点】

    ★ 更新走的是国内加速地址（gh-proxy.com），不用开 VPN。
    ★ 更新前【必须完全退出 Hermes】：
      点右上角 × 只是最小化到托盘，要右键托盘图标选【退出】。
    ★ 中途别关黑窗口；更新完它会告诉你成没成。


================================================
  第二部分：全局代理开关（通用）
================================================

【装别的东西（不是 Hermes）时用它】

双击 全局代理开关.bat

    [1]  开启全局代理
    [2]  恢复默认（关闭代理）
    [3]  查看当前状态
    [4]  一键修复（端口变了 / 断线了）
    [0]  退出

它做三件事，缺一个都不行：

    1. 系统代理    → 浏览器、桌面软件
    2. 环境变量    → pip / uv / git 等命令行工具
    3. git 代理    → ★ 关键的一条

为什么 git 要单独设：git 只认自己的配置，
不认 Windows 的"系统代理"开关。所以 VPN 明明
开着，git 还是在裸奔 —— 这就是 Hermes 装不上
的另一个原因。

★ 用完记得选 [2] 恢复。菜单上会一直挂着红字
  提醒你。这三样都是【持久】的，关窗口、重启
  电脑都不会自动消失：

    系统代理  → 存在注册表
    环境变量  → 存在注册表
    git 代理  → 存在 .gitconfig 文件

  而 LeapVPN 的端口是【连上节点才出现】的。
  VPN 一断，那些设置就指向一个死代理，
  pip / git 就会连不上网。

  选 [0] 退出时如果代理还开着，会弹窗问你
  要不要顺手关掉。（点窗口的 × 属于强杀，
  拦不住，所以还是用 [0] 退出比较稳妥。）


================================================
  文件夹里都有什么
================================================

  Hermes安装加速器.exe                      ← ★ 推荐入口（单文件，双击即用）
  Hermes安装加速.bat  + hermes-vpn.ps1    ← 同功能的老方式（留作备用）
  全局代理开关.bat    + proxy.ps1          ← 通用开关一对
  使用说明.txt                              ← 就是本文件
  _维护工具.py / _打包器.cs                 ← 我改代码/重新打包用的，你不用管
  Hermes-Setup.exe                          ← 安装包（放这儿也认，
                                              放 D:\下载\ 也认；
                                              ★ 找不到会自动联网下载）
  更新日志\                                 ← 更新时自动生成，存英文原文

注意：
  · exe 是【单文件】，不依赖上面任何文件，拷到哪都能用。
  · bat 和对应的 ps1 必须待在同一个文件夹里，分开了 bat 会找不到脚本。
